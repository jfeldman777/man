Две стороны

На каждой стороне — 4 разных числа от 1 до 8. Сторона A одна, вариантов B может быть несколько.

Справка

Ввод

  • Сторона A — одно четырёхзначное число (цифры 1–8, без повторов).
  • Сторона B — одно или несколько чисел в полях; у последнего поля кнопки + и −.

Кнопки

  • ПОКАЗАТЬ ВСЕ ЧЕТВЁРКИ — 38 вариантов B (цифры по возрастанию, сумма чётная). На кнопке — код; подсказка при наведении из quad-hints.txt (1258 - текст), иначе ?.
  • СЧИТАЕМ — расчёт для A и B: если выбраны четвёрки — по ним; иначе по полям B. Один B — краткий итог; несколько — список В#### с финалами.
  • БЕСКОНФЛИКТНЫЕ — из 38 четвёрок оставляет только те B, где ни в одной из 8 партий с данной A нет войны.

Результаты

  • Итого финалы — сколько раз встретились война, кооперация, конкуренция.
  • ПОДРОБНЕЕ — таблица всех 8 партий для этого варианта B.

Правила партии (кратко)

  • 8 партий: 4 старта с цифр A, 4 — с цифр B; ходы чередуются A → B → A → B.
  • За пару ходов: равенство — конкуренция (+2/+2); соседние цифры — кооперация (+3/+4); иначе — война (−100/+1).
  • Конец: война (−100), или повтор позиции (последние ходы A и B как раньше).
  • При равных очках за ход выбирается меньшее число из доступных.
